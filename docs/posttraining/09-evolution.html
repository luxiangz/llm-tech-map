大语言模型后训练技术体系深度调研 · 第 9 章

技术演进与争议：十年主线与未决问题

本章结论：后训练的十年演进不是"新方法淘汰旧方法"的单向过程，而是三条长期主线的反复交叉：信号密度（稀疏→密集：outcome→PRM→逐 token 分布）、数据分布（off-policy→on-policy：示范→学生轨迹）、成本结构（管线简化：PPO 四模型→GRPO/RLOO 三模型→DPO 两模型→OPD 学生+冻结教师）。每条主线都有"钟摆"现象：RLHF 兴起后 DPO 以 1/10 成本回归监督式训练；重 RL 的 R1 之后 Qwen3/TM 用蒸馏回收分布；蒸馏的分布失配问题（GKD 2023）在 2025 年以 OPD 之名成为主角。当前最大的三个争议：RLVR 是否扩展能力边界（pass@k 之争）、RLVR 增益中有多少是真实的（spurious rewards）、OPSD 的增益来自特权信息还是上下文诱导（OP²SD 解剖）。

9.2 争议一：RLVR 是否扩展能力边界（pass@k 之争）

正方（不扩展）：Yue et al. [2504.13837]——Qwen2.5-7B/14B/32B 等 7 模型 × SimpleRLZoo/DAPO/DeepCoder 等 RLVR 模型 vs 各自 base：pass@k 交叉点在 k≈几十到几百（例：Minerva 32B base 在 k=128 反超 RL 模型 9 点；Qwen2.5-7B 训练中 pass@1 26.1→42.5 而 pass@256 66.3→64.3 不升反降）；六算法（PPO/GRPO/RLOO/ReMax/Reinforce++/DAPO）彼此相近；机制解释：RL 输出落在 base 分布低 PPL 区域——"锐化而非扩展"；蒸馏反例：R1-Distill 的 pass@k 曲线整体高于 base——蒸馏可注入新模式。B

反方（有条件扩展）：

  • ProRL [2505.24864]（NVIDIA）：长时程 RL + KL 控制 + 参考策略重置，大 k 下持续超 base（含 base 采样全零分的题）；扩展幅度与 base 能力和训练时长正相关。
  • CoT-Pass@K [2506.14245]：按推理链正确性（而非终答）度量，RLVR 确实扩展边界——分歧部分源于"能力"的度量定义。
  • Curriculum RL [2606.22317]：pass@k 定位边界→教师定向注入→RL 巩固，pass@1 与 pass@256 同升（较 base +9.8）——扩展需要外部注入（又回到蒸馏通道）。
  • QuestA [2507.13266]（部分解提示降难度）：1.5B 上 AIME24 +10.7。
  • Guru [2506.14965]：92k 六域可验证语料，RL 提升 pass@k，欠预训练域有真实技能习得。

现状判定（多源综合，B）：共识正在形成——"标准 GRPO/PPO 家族 + 常规题池"下 RLVR 主要是重新分配概率质量（pass@1↑、大 k 不升或降）；真正扩边界需要长时程、外部知识注入或更好探索。基准侧警告：常规数学题池在 pass@1024 下对现代 base 已近饱和（MATH-Beyond [2510.11653]），双方实验都受此影响。

9.3 争议二：RLVR 增益的真实性（spurious rewards）

Shao et al. [2506.10947]：Qwen2.5-Math-7B 上随机奖励 +21.4 vs 真奖励 +29.1（MATH-500）——与正确性零相关的"伪奖励"经 GRPO 训练也能大涨；机制：GRPO 的 clip 偏置放大预训练习得的高先验行为（如 code reasoning 风格 65%→90%+）。边界（关键）：高度模型相关——Llama3/OLMo2 上常无效。含义：(1) 单一模型（尤其 Qwen 系）上的 RLVR 增益可能高估真实能力增量；(2) 真奖励仍比伪奖励多约 8 点，说明奖励信号有真实成分；(3) 与 Dr.GRPO 的偏置分析、Yue 的"锐化论"互相印证。B

9.4 争议三：OPSD 的增益来自哪里

  • OP²SD [2608.09228]：特权解换成别题的 worked example，9 组模型-基准中 8 组不降甚至更好；琐碎示例（1+1）则完全失效——增益或主要来自"数学 worked-example 上下文诱导的教师行为"（更专注/更规范的推理风格），而非特权解的内容。
  • Many Faces [2605.11182]：特权信息编码"共享规则"时有效、编码"实例特定事实"时失效——与 OP²SD 互洽。
  • [2605.06188]：hindsight 蒸馏只压实"本可答对"的轨迹，修不了失败轨迹。
  • [2610.18613]：SDPO/OPSD 增益大部分可解释为过拟合。
  • [2607.01763]：持续训练场景 SDPO 遗忘/塌缩，GRPO 更稳。

判定：OPSD 的工程效果（token 效率、无 RM）有 A 级原始证据，但机制解释（特权信息内容 vs 上下文诱导）与稳健性（持续训练、跨规模）均未定论——引用时应同时给出原始论文与批判文献。

9.5 其他未决争议

争议双方与证据

9.6 演进的驱动逻辑总结

  1. 成本驱动：每次"管线简化"都催生新主流（PPO→GRPO 去 critic；RLHF→DPO 去 RM 去采样；RL→OPD 把奖励换成更便宜的教师前向）。
  2. 信号密度驱动：outcome→PRM→隐式 PRM→逐 token 分布，监督粒度持续变细；信息论上从 $O(1)$ 到 $O(N)$ bits/episode。
  3. 分布正确性驱动：SFT→RFT→RL/OPD/OPSD，被监督状态从"别人的"走向"自己的"；DAgger 理论（2011）预言了这条线。
  4. 可验证性驱动：奖励从人评→RM→规则验证器→环境反馈，客观性越高 hacking 风险越低，但适用域越窄。
  5. 钟摆现象：简化派与 expressive 派交替主导——DPO 之后在线方法回归（OAIF/迭代 DPO）；重 RL 之后蒸馏回归（Qwen3/TM）；每次回归都带着前一阶段解决的问题（如 OPD 带着 RL 的基建与 GKD 的理论）。
