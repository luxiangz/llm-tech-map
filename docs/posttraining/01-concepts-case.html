大语言模型后训练技术体系深度调研 · 第 1 章

概念体系与统一案例：先分清层级，再谈机制

本章结论（先读这段）：SFT、RL、OPD、OPSD 不是同一层级上的四个"平行选项"，而是"监督信号类型 × 数据生成方式 × 优化目标"三个正交设计维度上的不同取值组合。SFT 用示范的硬标签在别人的轨迹上做极大似然；RL 用标量奖励在自己采样的轨迹上做策略优化；OPD 用外部教师的逐 token 分布在学生自己的轨迹上做分布匹配；OPSD 把外部教师换成同一模型在更丰富上下文（特权信息）下的自己。四者的数学目标可以在同一个 KL 框架下统一表述（第 7 章），但工程实现、成本结构与失败模式差异巨大。本章先建立术语分层与统一案例，后续各章在同一套维度下逐个深挖。

1.1 概念分层：范式、数据、信号、目标、算法是五件事

调研文献时最容易混淆的是把不同层级的概念放在同一句话里比较。本报告统一使用以下五层分解，每个方法都要在每一层上说清楚自己的取值：

层级含义例子（同一方法在不同层可以自由组合）
① 训练范式回答"学习信号的本质是什么"：模仿示范、匹配偏好、最大化奖励、匹配教师分布模仿学习、偏好学习、奖励驱动 RL、知识蒸馏
② 数据生成方式训练样本由谁的分布产生：固定数据集 / 教师生成 / 当前学生采样（on-policy）/ 环境交互UltraFeedback 离线偏好对 vs Llama 3 每轮重新采样的偏好对
③ 监督信号信号本身长什么样：token 硬标签、token 软分布、成对偏好、二元好/坏、序列级标量奖励、逐步骤分数、文本反馈PRM800K 的逐步标注 vs GSM8K 验证器的终答对错
④ 优化目标（损失）把信号变成数的数学形式：交叉熵、各方向 KL/JSD、Bradley–Terry 损失、clipped 策略梯度同为"偏好"信号，DPO 与 ORPO 的损失完全不同
⑤ 优化算法如何估计梯度并更新：监督梯度、策略梯度（REINFORCE/PPO/GRPO）、闭式重参数化同为反向 KL 蒸馏目标，MiniLLM 用策略梯度、GKD 用监督式梯度

由此得到几条本报告反复使用的辨析规则：

  • 训练范式 ≠ 优化算法。PPO/GRPO/RLOO 只是 RL 范式下的算法选择；把 GRPO 与 DPO 并称为"两种训练方法"没有错，但要清楚它们处在不同层（一个是算法，一个是从目标函数推导出的损失）。
  • 在线采样 ≠ on-policy 更新。"训练中产生了新数据"不等于 on-policy：教师生成的数据在训练循环内产生，但对更新而言仍是 off-policy（生成分布是教师的）。on-policy 的严格定义是采样策略与被更新策略为同一策略（或近似同一策略）（详见第 7 章图 6）。
  • 数据生成方式 ≠ 监督信号。都在学生轨迹上训练，RL 给标量、OPD 给逐 token 分布、RFT 给过滤后的硬标签——三者的学习信号密度完全不同。
  • 独立教师蒸馏 ≠ 同模型自蒸馏。OPD 的教师是另一个（通常更强的）模型；OPSD 的教师是同一权重在不同输入条件下的分支。混用"自蒸馏"一词时必须注明是数据空间（SDFT）、层级间（Born-Again）还是上下文间（OPSD 原义）。

1.2 四个核心对象的严格定义

缩写全称与出处严格定义（本报告采用）
SFT Supervised Fine-Tuning（监督微调）；现代形态定型于 InstructGPT [2203.02155] 的 SFT 阶段，思想源于指令微调 FLAN [2109.01652]/T0 [2110.08207] 在示范数据集 $\mathcal{D}=\{(x^{(i)},y^{(i)})\}$ 上最小化 token 级交叉熵（等价于对示范极大似然）的微调。等价于行为克隆（BC）+ 预训练先验：不提供高于示范质量的监督信号，上限由示范的覆盖与正确性决定。A
RL Reinforcement Learning；LLM 语境指 RLHF [1706.03741] 谱系与可验证奖励 RLVR（命名自 Tulu 3 [2411.15124]） 在当前策略自采样（on-policy rollout）的轨迹上，以标量奖励（学习式 RM 分数或规则验证器输出）为目标、带 KL/信任域约束地更新策略参数。奖励是序列级稀疏信号（outcome）或逐步信号（process）。
OPD On-Policy Distillation（在线策略蒸馏）；术语最早作为标题出现于 GKD "On-Policy Distillation of Language Models" [2306.13649]（2023），2025 年经 Thinking Machines 博客（2025-10-27）与 Qwen3 技术报告 [2505.09388] 的实践重新定义为主流范式 学生模型自己采样轨迹，外部教师在学生访问的每个前缀上提供监督（最典型：逐 token 的反向 KL / 广义 JSD 损失），学生只在该信号上更新参数、教师冻结。等价视角：把每 token 的"负反向 KL"当作密集奖励的 RL（第 4、7 章）。A
OPSD On-Policy Self-Distillation（在线策略自蒸馏）；术语与方法的原始论文为 "Self-Distilled Reasoner"（Zhao et al., 2026）[2601.18734]，同期独立起点为 SDPO（Hübotter et al., 2026）[2601.20802] 同一模型在两种上下文中分别充当学生与教师：教师分支额外看到特权信息（数据集参考解、环境文本反馈、技能库等）从而获得更强的条件分布；在学生自己采样的轨迹上做逐 token 分布匹配，梯度只更新学生侧。判别要件：同模型 + 特权条件 + 学生轨迹 + 软分布监督（第 5 章）。

检索勘误提示：调研中核验并纠正了多个流传的错误 arXiv 编号，正文引用一律以核验过的编号为准。重要勘误包括：SDFT 是 2402.13669（非 2404.10631）；ReST 是 2308.08998（非 2307.14551）；ReST-EM 是 2312.06585（非 2312.06562）；V-STaR 是 2402.06457（一作 Hosseini，非 2410.06161）；DistiLLM 是 2402.03898（非 2401.05978）；Free Process Rewards 是 2412.01981（非 2502.19295）；Apple 蒸馏缩放律是 2502.08606（非 2501.16294）；RLOO 是 2402.14740（非 2402.14730）。完整清单见文献库。

1.3 统一案例：一道贯穿全文的数学题

问题 $x$：商品原价为 100 元，先涨价 20%，再降价 20%，最终价格是多少？
参考答案 $y^{gold}$：$100\times 1.2 = 120$ 元；$120\times 0.8 = 96$ 元。最终价格 96 元（不是直觉错误答案 100 元）。
基础模型 $M$：已完成预训练、尚未后训练；设定它可以被微调，且训练时可访问一个（可选的）教师 $T$ 与一个规则验证器 $V$（比对最终答案是否为 96）。

下面用通俗语言把六类方法在同一道题上过一遍。每种方法都回答同样九个问题：输入是什么 / 训练数据从哪来 / 谁生成样本 / 谁提供监督信号 / 优化目标是什么 / 哪些参数更新 / 推理行为如何变化 / 需要什么额外资源 / 什么条件下失效。案例只用于解释机制，不代表各方法在这道题上有一致的性能提升——性能结论一律以对应论文实验为准。

1.3.1 SFT：把写好的解答"抄"进模型

准备几千道类似题目的高质量人工解答（每一步清晰、格式统一），在 $(x, y^{gold})$ 对上最小化交叉熵：模型逐步学会在"涨价 20%"之后输出"$100 \times 1.2 = 120$"。监督信号就是示范 token 本身；样本由人类（或教师模型）生成，与模型当前状态无关（off-policy）。推理变化：输出格式稳定、风格统一；但若示范只覆盖"先乘后乘"一种写法，模型遇到需要不同解法的变体时只能靠预训练先验兜底——行为克隆的复合误差理论（DAgger [1011.0686]）指出，per-step 误差 $\varepsilon$ 会沿序列复合为 $O(T^2\varepsilon)$。A 失效条件：示范覆盖不足或含系统性错误（如把降价 20% 写成 $100-20$）；此时 SFT 会忠实复制错误，且没有任何纠错信号。

1.3.2 RL：让答对的解法被强化

把题目交给模型自己采样 $G$ 条完整解答，用验证器 $V$ 判分：最终答案等于 96 得 +1，否则 −1（DeepSeek-R1 的规则奖励即此形态 [2501.12948]）。组内比较（GRPO：[2402.03300]）：比同组平均分高的解答整体概率上升，低的整体下降。监督信号是每条轨迹一个标量——哪一步算错并不知道（credit assignment 病理）。推理变化：模型被"锐化"到更可靠地走通自己本来就会的解法；是否能学会全新解法存在争议（pass@k 争论，第 9 章）。失效条件：验证器不可得或可被钻空子（reward hacking [2209.13085]）；探索坍缩；奖励噪声下 GRPO 的 clip 偏置可能放大预训练先验而非真学（spurious rewards [2506.10947]）。B

1.3.3 OPD：学生做题，教师逐字批改

模型（学生）自己采样一条推理——可能第三步写错了。外部教师 $T$（如一个 RL 训好的同规模或更大模型）不动学生的文字，而是在学生的每个前缀（题目 + 学生已写的每一步）上给出"下一个 token 应该是什么"的完整分布，学生最小化自己分布与教师分布的反向 KL。哪怕学生第 2 步已偏离，教师也会针对"从那个错误状态出发该怎么走"给出密集修正——这正是 Thinking Machines 说的"sample trajectories from the student and use a teacher to grade each token"。信号密度：RL 每条轨迹传 $O(1)$ 比特（一个分数），OPD 传 $O(N)$ 比特（每个位置一个分布）。B（博客+论文交叉）失效条件：教师必须能对学生造成的（对教师而言不自然的）前缀给出良构分布，师生差距过大时信号失效（VOLD [2510.23497]：无 SFT 冷启动对齐时 OPD "fails to provide meaningful guidance"）；教师逐前缀推理是吞吐瓶颈。

1.3.4 OPSD：看得到答案的自己，教看不到答案的自己

不引入外部教师。同一权重两个分支：学生分支只见题目；教师分支额外看到参考解 $y^*$（含 $120\times 0.8=96$ 的完整过程）——"特权信息"。教师分支由于看了答案，能在学生的任意前缀上给出更可靠的下一 token 分布；学生在自己采样的轨迹上逐 token 向教师分支靠拢（Zhao et al. 2026 [2601.18734]）。变体 SDPO（[2601.20802]）把特权信息换成环境文本反馈：教师分支看到"你第三步算错，正确应为 96"的报错后重打分，学生向"知情版自己"学习。推理变化：推理时不带特权信息，但"消化"了特权信息的行为被内化进权重。失效条件：特权信息与题目无关时（OP²SD 解剖 [2608.09228]：换成别的题的 worked example 效果几乎不降）——增益来源存疑；风格 token 的 KL 失衡（原文报告 wait/think 类 token KL 是数学 token 的 6–15 倍，须逐 token 裁剪）。B

1.3.5 传统 KD：教师写范文，学生背范文

教师 $T$ 先生成一批解答（序列级蒸馏 SeqKD [1606.07947]），或在固定题库上输出软标签（Hinton KD [1503.02531]）。学生在这个与自己的状态分布无关的数据上训练——学生从未在自己会到达的前缀上被纠正，长链推理时分布失配复合（GKD 论文的核心批评，[2306.13649]）。A

1.3.6 DPO 等偏好优化：在"96 分回答"与"100 分回答"之间选边

收集成对比较：$(x, y_w=$ 解到 96 的回答$)$ vs $(x, y_l=$ 解到 100 的回答$)$。DPO（[2305.18290]）直接增大隐式奖励差 $\beta\log\frac{\pi(y_w|x)}{\pi_{ref}(y_w|x)}-\beta\log\frac{\pi(y_l|x)}{\pi_{ref}(y_l|x)}$，无需 RM 与采样。监督信号是相对偏好（谁更好），不含绝对分数；离线数据上无探索。失效条件：偏好数据 off-policy 漂移、chosen 似然坍缩、长度偏置（第 6 章）。

1.6 术语表（本报告统一用法）

术语本报告定义与边界
on-policy / off-policy按"采样策略与更新策略是否同一"判定，而非"训练中是否产生新数据"。PPO/GRPO 的 minibatch 复用造成轻微 off-policy（clip 容忍）；教师采样数据即使在线产生，对学生更新仍是 off-policy。RLHF 中 RM 训练分布与策略分布的错位是 reward hacking 的根源之一。
示范（demonstration）完整的 (输入, 期望输出) 对。示范质量上限 = SFT 监督上限。
奖励模型 RM / ORM / PRMRM：任何把 (x,y) 映射为标量的模型；ORM（outcome）：只看最终结果（含学习式 RM 与规则判分器）；PRM（process）：逐步骤打分。隐式 PRM：由策略/参考模型的对数概率差构造、无需过程标注（[2412.01981]、PRIME [2502.01456]）。
参考模型 π_refRLHF/RLVR 中冻结的锚点（通常为 SFT 模型），以 KL 惩罚限制策略漂移。它不提供正向监督目标，因此"参考模型 ≠ 教师"。
教师（teacher）提供被优化目标分布的模型。三种形态：外部强模型（OPD/传统 KD）、同模型特权分支（OPSD）、自身冻结/EMA 副本（SDFT、SDPO 的一类实现）。
特权信息（privileged information）训练时教师分支可见、部署时学生不可见的信息：参考解、答案 hint、环境报错、judge 评语、技能库、高分辨率视角等。OPSD 家族按特权形态分亚类（第 5 章）。
软监督 / 硬监督软=分布（logits/概率），硬=选定 token。同一轨迹上软监督每步传一个分布、硬监督每步传一个选择。
RLVRReinforcement Learning with Verifiable Rewards：奖励来自可执行验证器（答案比对、单元测试、约束校验），Tulu 3 命名并系统化 [2411.15124]。
拒绝采样微调 RFT采样多条→按奖励/正确性过滤→在保留样本上 SFT。可视为"把 RL 的采样-评估循环压扁成离线迭代"的硬标签方法。
奖励黑客（reward hacking）代理奖励上升而真实目标下降。形式化见 Skalse et al. [2209.13085]：除特殊情形外代理奖励必然可被过度优化。
证据等级 A/B/C本报告内部规范：A=有数学推导或直接实验支持（且出处原文核验）；B=作者报告的实验，条件有限或尚缺独立验证；C=机制解释、推断或未充分验证假设。非通用学术评级。
