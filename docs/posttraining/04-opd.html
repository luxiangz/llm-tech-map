大语言模型后训练技术体系深度调研 · 第 4 章

OPD 深度机制：在线策略蒸馏

本章结论：OPD 的定义性机制只有一句话——轨迹由学生采样，监督由教师在学生的每个前缀上逐 token 给出。它的研究史是三个设计轴的逐步探索：散度方向（前向 KL→反向 KL→广义 JSD/skew KL）、数据来源（固定集→教师采样→学生 on-policy）、优化算法（监督梯度 vs 策略梯度）。GKD（2306.13649，原标题即 "On-Policy Distillation of Language Models"）2023 年完成系统化；2025 年 Thinking Machines 博客（10-27）把它重述为"per-token 反向 KL = 密集奖励的 RL"，实现上是 KL 正则 RL 代码的"一行改动"；Qwen3 技术报告 Table 21 给出迄今最重要的工业对照：同起点下 on-policy 蒸馏以 1,800 GPU 时（RL 的 1/10）在 AIME'24 上 74.4 分超过 RL 的 67.6，且把 pass@64 从 90.0 提到 93.3（RL 不提升 pass@64）。A 注意：不同论文的"OPD"在损失、粒度、流程上并不相同，本章逐篇记录实现，不归并为唯一流程。

4.2 机制拆解：以统一案例走一遍 GKD 与 TM-OPD

4.2.1 GKD 的三轴框架（Agarwal et al., ICLR 2024 [2306.13649]）

$$ \mathcal{L}_{\text{GKD}}(\theta)=(1-\lambda)\,\mathbb{E}_{(x,y)\sim\mathcal{D}}\big[\mathcal{D}(p_T\|p_S^\theta)\big]+\lambda\,\mathbb{E}_{x\sim\mathcal{D},\,y\sim p_S(\cdot|x)}\big[\mathcal{D}(p_T\|p_S^\theta)\big], \quad \mathcal{D}(p_T\|p_S)=\frac{1}{|y|}\sum_n \mathcal{D}\big(p_T(\cdot|y_{<n},x)\,\|\,p_S^\theta(\cdot|y_{<n},x)\big) $$ $$ \mathcal{D}_{JSD}^{(\beta)}(P\|Q)=\beta\,\mathrm{KL}\big(P\,\|\,\beta P+(1-\beta)Q\big)+(1-\beta)\,\mathrm{KL}\big(Q\,\|\,\beta P+(1-\beta)Q\big) $$

λ=0 退化为标准监督 KD；λ=1 为纯 on-policy KD；教师采样数据对应 SeqKD。广义 JSD 有界（支撑不相交时仍有限），这是 GKD 能绕开策略梯度、用监督式梯度反传的关键。论文对分布失配的原文论述（HTML 核验）："distilling auto-regressive student models using such approaches results in train-inference distribution mismatch"；on-policy 训练形成 "a form of feedback loop akin to what we observe in RL"；把 KD 视为 "imitation learning with an interactive expert"（DAgger 系）。实验（T5 家族，教师 T5-XL≈3B）：on-policy GKD 相对基线 KD 平均相对增益 2.1×/1.7×/1.9×（摘要/翻译/推理）；只用 5% XSum 数据（无 gold 摘要）超过全量监督 KD；GSM8K 自蒸馏（教师=同规模）学生反超教师。A

4.2.2 Thinking Machines 的 OPD（2025-10-27，Lu/Peng/Schulman）

$$ r_t=-\,\mathrm{KL}\big(\pi_\theta(\cdot\mid y_{\le t},x)\,\|\,\pi_T(\cdot\mid y_{\le t},x)\big),\qquad A_t=r_t,\qquad \gamma=0 $$

实现："a one-line change on top of RL implementations which use KL regularization"——把正则模型换成教师、查询教师 logprob、per-token advantage 设为负反向 KL，沿用重要性采样损失。信息密度论证原文："RL only teaches O(1) bits per episode. In contrast, distillation teaches O(N) bits per episode." 反向 KL 的不可 hack 性："low KL always corresponds to a high probability of desirable behavior from the teacher's point of view"。

四组实验（博客数字，B 级；引用 Qwen3 TR 的数字为 A 级）：

  • 数学推理：学生 Qwen3-8B-Base，OpenThoughts-3 400k SFT 至 AIME'24 ~60%，OPD 约 150 步 / 77k prompts 达 70%。引用 Qwen3 Table 21：RL 17,920 GPU 时→67.6/61.3（AIME'24/GPQA），OPD 1,800 GPU 时→74.4/63.3。
  • 个性化/灾难回退：Qwen3-8B 中途微调后 IF-eval 85%→79%；以微调前模型为教师做 OPD：79%→83%，且内部 QA 知识保持（41% vs 教师 43%）；对照"在自己的样本上 SFT"任何非零学习率都继续退化——有限 batch 使 SFT 训练逐渐偏离 on-policy。
  • 效率：对齐外推 SFT-2M 同水平：9× FLOPs / 18× GPU 时；计入教师造数据成本约 30×；学习 RL 训好的策略只需 7–10× 更少梯度步（累计 50–100× 算力）；单 prompt 5,120 条 rollout 逼近教师。
  • 逐 token 信用分配案例：教师惩罚的是"把推理引向歧途的起始短语 token"（forking tokens），对学生"前缀给定后已不可避免的错误答案"不罚——比 outcome 奖励的信用分配精细得多。

4.3 为什么可能比结果奖励更密集：信号密度与信用分配

统一案例：学生第三步写错。RL 的处理——整条轨迹 −1，正确的第一、二步也被压低；OPD 的处理——教师在每个前缀给出完整分布，第三步处教师的"应为 120×0.8=96"分布与学生分布的 KL 大、前两步 KL 小，梯度自动集中错误处。两条形式化支撑：(1) $O(1)$ vs $O(N)$ bits/episode（TM 博客）；(2) MiniLLM 的策略梯度展开中教师−学生 log-ratio 即逐步回报（第 7 章 T4 给推导）。注意边界：OPD 的信号密度来自教师分布，因此渐近上限是教师——RL 可超越教师（Stiennon 摘要实验），蒸馏不能。A

4.6 计算开销结构与失败模式

  • 开销：学生采样（DistiLLM 报告可占 on-policy 训练总时长 ~80%）+ 教师对学生每个前缀的一次 forward（可并行、可 top-K logprob 截断、可用部分 rollout）；无 RM、无 critic、无组内多 rollout（对比 GRPO 每题 8 条 × 16k token）。
  • 失败模式：① 教师 OOD——学生前缀对教师非自然，教师须仍给出良构分布（TM 博客与 VOLD 共同强调）；② mode-seeking 反向 KL 牺牲多样性（GKD 权衡讨论）；③ 师生差距过大→信号失效（VOLD：无 SFT 冷启动时 OPD 无有效指导）；④ 黑盒教师无 logits → 需对抗式判别器替代（GAD [2511.10643]：判别器=与学生共同进化的 on-policy RM，GPT-5 级教师可用）；⑤ 渐近上限=教师（不能超越教师，除非教师本身来自 RL）。

4.8 回答任务书 5.2 节问题

问题要点（出处见上文）
on-policy 属性体现在哪里？被监督的前缀由学生当前策略采样（GKD λ=1 / TM OPD / Qwen3 on-policy 阶段），梯度在学生自己访问的状态分布上求期望——DAgger 意义上的 on-policy 修正。教师采样（SeqKD/R1 蒸馏）不是。
学生轨迹如何进入训练？作为"状态载体"：训练不打分整条轨迹，而是沿学生轨迹的每个前缀取教师分布做逐 token 损失（GKD：teacher-forced 散度反传）。
教师针对什么提供监督？学生的每个前缀（学生真实到达的状态），不是教师自己的生成。
教师输出什么？逐 token 完整分布（白盒 logits / top-K / API logprob）；变体：黑盒对抗判别器（GAD）；序列级硬标签是 off-policy 的 SeqKD，不属 OPD。
与 KD/SFT/模仿/KL-RL 的区别？与 KD/SFT：数据分布轴（学生 vs 教师/固定集）；与模仿学习：OPD=interactive expert 的 DAgger 式实现；与 KL-RL：形式等价（第 7 章 T4），差别在信号来源（教师 vs 奖励）与上限（教师 vs 可超教师）。
损失/散度/粒度差异？前向 KL（覆盖、幻觉风险）vs 反向 KL（集中、多样性损失）vs JSD/skew KL（折中、有界可监督梯度）；序列级 vs token 级粒度在自回归下不等价（GKD §3）。
为何比结果奖励密集？$O(N)$ vs $O(1)$ bits/episode；信用分配自动落在 KL 大的位置（forking tokens 案例）。
教师能力/兼容性/成本/分布的影响？教师须对学生前缀稳健（OOD）；师生差距过大信号失效（VOLD 冷启动必要性）；教师逐前缀前向是吞吐瓶颈（DistiLLM 4.3× 缓解）；白盒兼容性（词表/架构）决定能否全词表蒸馏。
