研究缺口与后续方向

本章定位：区分"较有共识的结论""尚未充分验证的主张""实验可比性问题""概念边界问题"与"值得投入的研究方向"，并如实记录本次调研的方法学局限。

1. 较有共识的结论（多源独立证据交叉）

  1. SFT 主要教格式与覆盖内行为，能力泛化依赖覆盖广度；分布外退回记忆化（LIMA/InstructGPT/FLAN/OMI-2/Chu；A/B 级）。
  2. SFT/蒸馏打底 + 偏好或 RL 锐化 + 迭代中重置数据是 2024 年后工业配方的稳定模式（InstructGPT/Llama 3/Tulu 3/R1/Qwen3 一致；A 级）。
  3. 监督/蒸馏类比在线 RL 便宜一到两个数量级（Qwen3 Table 21、Tulu 3、TM 博客三方独立；A/B 级）。
  4. 小模型 + 强教师时蒸馏优于直接 RL（R1 蒸馏节与 Qwen3 独立同向；A 级）。
  5. RL 提升采样效率（pass@1/cons@k）证据充分；"扩展能力边界"需要附加条件（Yue/ProRL/CoT-Pass@K/Guru 分歧正在收敛到该表述；B 级综合）。
  6. 学习式 RM 会被过度优化（reward hacking），KL/信任域是必要护栏；规则奖励下可放松（Skalse/Secrets I/InstructGPT/DAPO；A 级）。
  7. off-policy 数据上的分布失配是真问题：GKD/TM/Qwen3-2507/VOLD 四个不同角度的同向证据（A/B/C 级）。
  8. on-policy 数据或负梯度（mode-seeking）系统性优于离线纯 MLE（Xiong 理论+Guo 实证+Tajwar 统一分析；A 级）。

3. 实验可比性问题（引用数字时的系统性风险）

  1. 起点不一致：多数"RL vs 蒸馏"对照从不同 checkpoint 出发；Qwen3 Table 21 的同起点三分支是少数例外。
  2. 指标口径：pass@1 / avg@k / cons@k / pass@64 混用；温度与采样参数不统一（pass@k 对温度敏感）。
  3. 预算不披露：R1 未公布总 GPU 时；Qwen3 蒸馏数据规模未在正文给出；多数论文的"步数"不可换算。
  4. 题池饱和与污染：常规数学题在 pass@1024 下对现代 base 近饱和（MATH-Beyond）；污染影响 RLVR/蒸馏对比的公平性。
  5. 模型家族偏置：Spurious Rewards 显示 Qwen 系的 RLVR 增益部分来自 clip 偏置放大先验——单家族结论不可外推。
  6. LoRA vs 全参：OPSD 原文用 LoRA（教师=base 即冻结），与全参场景的"冻结初始"语义不同；跨实现比较需谨慎。

4. OPD 与 OPSD 的定义边界问题

  • OPD 无注册商标式定义：GKD（2023，λ 混合+JSD）、MiniLLM（反向 KL+策略梯度）、TM（逐 token 反向 KL+RL 更新器）、Qwen3（logits 对齐 KL）都自称或被称 OPD，损失与流程实质不同——引用时必须逐篇注明实现。
  • OPSD 是 2026-01 才定名的对象：Zhao 与 Hübotter 双起点即有分歧（特权=参考解 vs 环境反馈；教师冻结 vs EMA）；follow-up 按特权形态分化（技能/latent/自构造/多模态）。不可把某一篇的上下文设计或监督机制当成家族必要条件（任务书 5.3-9 的要求在此落地）。
  • "自蒸馏"一词的四义：上下文间（OPSD）、数据空间（SDFT）、层级间（BYOT）、代际间（BAN）——文献混用最严重的术语之一。
  • "LDC (2025)"不存在（三路查证）：传述中的机制=Zhao 2026；同名论文=Snell 2022（off-policy 硬标签）。引用时应回到这两篇。

5. 值得进一步研究的理论、算法与工程问题

理论

  1. 信号密度的理论化：$O(1)$ vs $O(N)$ bits/episode 是定性论证；缺"每比特监督对样本复杂度的边际贡献"的定量刻画（PRM 的 $O(T)$ 比特与蒸馏的 $O(N)$ 比特如何折算）。
  2. OPSD 的可辨识性：特权信息在什么条件下携带"实例特定信息"而非仅"共享规则"（Many Faces 的二分法需要理论化）。
  3. 蒸馏-RL 混合目标的统一分析：GKD 的联合目标与 SRPO 的"正确走 GRPO、失败走 SDPO"路由，缺收敛性与偏差的系统比较。
  4. 自蒸馏不动点：SDPO 型 EMA 自教师的收敛行为（无正则会塌缩的 36.1% 现象）缺理论解释。

算法

  1. on-policy 蒸馏的采样-复用调度（DistiLLM 线）与教师 top-K 截断的误差-吞吐权衡；
  2. 特权信息的自动构造（U-OPSD 的多数票、LOPD 的 latent 学习）与特权质量的关系；
  3. RL 后"蒸馏回收分布"（Qwen3 pass@64 90→93.3 现象）作为标准阶段的系统化；
  4. 多轮 Agent 任务的信用分配（SDPO/隐式 PRM 向 agentic 域延伸）。

工程

  1. 教师逐前缀推理的批处理/部分 rollout/KV 复用（rollout 占 RLHF 迭代 81.2% 的教训同样适用于 OPD）；
  2. 异步 rollout-learner 解耦（AsyncOPSD 类工作的系统验证）；
  3. 黑盒教师蒸馏的判别器稳定性（GAD 线）；
  4. 评测基建：统一 pass@k 与熵报告口径的社区规范。
